Distributed workers

PREPARING

Arrivals are assigned once across the shared schedule. Global percentiles merge histogram buckets. Live values are the latest received worker measurements. Missing final results are unknown, and make the run fail. Unreported planned arrivals can include work canceled before admission. Worker CPU and heap are per process; in-flight peaks sum worker peaks as an upper bound.

Target-server telemetry

WAITING

Server metrics can include unrelated traffic. Gauges show sampled values; counters show observed rates across continuous readings. Missing and reset intervals leave gaps. Sampling includes drain, can miss spikes and early traffic, and adds observer load. Live charts use received snapshots; final charts use the retained scrape timeline. Telemetry coverage is separate from load checks and does not establish target health.

HTTP timing & connections

ms · cumulative

Observed intervals overlap and cannot be added together. Connection acquisition includes DNS, TCP, TLS, and pool waiting when they occur. First header byte starts at the attempt and can be informational headers; it is not server processing time. Reused connections have no DNS/TCP/TLS timing sample. Completed failed events are included; unfinished events have no duration.
